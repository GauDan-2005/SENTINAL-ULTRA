The `statrs` crate gives Rust users a solid set of probability distributions and statistical functions, but it is still thin on classical hypothesis testing — right now `src/stats_tests/` only offers Fisher's exact test. People reaching for `statrs` to do everyday inference keep having to drop down to Python/scipy for the most common significance tests, and there is a standing request (see https://users.rust-lang.org/t/mann-whitney-u-test/95005) for a native Mann-Whitney U test. The goal of this work is to grow `statrs::stats_tests` into a genuinely useful hypothesis-testing toolkit that offers a Pearson chi-square goodness-of-fit test, a one-way ANOVA F-test, a Mann-Whitney U test, a one-sample t-test, and a skewness test, each returning the test statistic together with its p-value and each numerically matching scipy's reference implementation. These additions live within the structure established by the Fisher module: one file per test under `src/stats_tests/`, each exposing a public function plus a dedicated error enum, with every new module registered in `src/stats_tests/mod.rs`. That shared module also includes a new `NaNPolicy` enum (a sibling of the existing `Alternative` enum) with three variants — `Propogate` (return `NaN` results when the input contains `NaN`), `Emit` (drop `NaN`s before computing), and `Error` (reject `NaN` input with the appropriate error) — re-exported so callers can write `use statrs::stats_tests::{Alternative, NaNPolicy};`. Comparisons in the accompanying tests go through the crate's existing `statrs::prec::almost_eq` helper, so the results must land within the stated tolerances; the test files remain unmodified.

Requirements: Add `src/stats_tests/chisquare.rs` exposing `pub fn chisquare(f_obs: &[usize], f_exp: Option<&[f64]>, ddof: Option<usize>) -> Result<(f64, f64), ChiSquareTestError>` that performs Pearson's chi-square test, where `f_exp` defaults to equal expected frequencies and `ddof` (default `0`) adjusts the degrees of freedom down from `f_obs.len() - 1`; its error enum `ChiSquareTestError` must provide `FObsInvalid` (returned when `f_obs` has length ≤ 1), `FExpInvalid` (returned when a supplied `f_exp` does not match the length and sum of `f_obs`), and `DdofInvalid` (returned when `ddof` is not at least two less than the number of categories, i.e. `ddof >= f_obs.len() - 1`). Add `src/stats_tests/f_oneway.rs` exposing `pub fn f_oneway(samples: Vec<Vec<f64>>, nan_policy: NaNPolicy) -> Result<(f64, f64), FOneWayTestError>` for a one-way ANOVA F-test over a collection of samples, with a `FOneWayTestError` enum covering `NotEnoughSamples`, `SampleTooSmall`, `SampleContainsSameConstants`, and `SampleContainsNaN`. Add `src/stats_tests/mannwhitneyu.rs` exposing `pub fn mannwhitneyu<T: PartialOrd + Clone>(x: &[T], y: &[T], method: MannWhitneyUMethod, alternative: Alternative) -> Result<(f64, f64), MannWhitneyUError>`, where the `MannWhitneyUMethod` enum offers `Automatic` (choose exact for small tie-free samples, otherwise the continuity-corrected asymptotic approximation), `Exact`, `AsymptoticInclContinuityCorrection`, and `AsymptoticExclContinuityCorrection`, and the `MannWhitneyUError` enum covers `UncomparableData`, `SampleTooSmall`, and `ExactMethodWithTiesInData`. Add `src/stats_tests/ttest_onesample.rs` exposing `pub fn ttest_onesample(a: Vec<f64>, popmean: f64, alternative: Alternative, nan_policy: NaNPolicy) -> Result<(f64, f64), TTestOneSampleError>` with a `TTestOneSampleError` enum covering `SampleTooSmall` and `SampleContainsNaN`. Add `src/stats_tests/skewtest.rs` exposing `pub fn skewtest(a: Vec<f64>, alternative: Alternative, nan_policy: NaNPolicy) -> Result<(f64, f64), SkewTestError>` (a D'Agostino skewness test requiring at least 8 observations) with a `SkewTestError` enum covering `SampleTooSmall` and `SampleContainsNaN`. Every error enum should implement `std::error::Error` (and `Display`) and compare with `PartialEq` so callers can match on specific variants.

To pin down the expected numerics: `chisquare(&[16, 18, 16, 14, 12, 12], None, None)` must return statistic `2.0` and p-value `0.84914503608460956`, while supplying `Some(&[16.0, 16.0, 16.0, 16.0, 16.0, 8.0])` as `f_exp` yields statistic `3.5` and p-value `0.62338762774958223`; `chisquare(&[16], None, None)` must be `Err(ChiSquareTestError::FObsInvalid)` and `chisquare(&[16, 18, 16, 14, 12, 12], None, Some(5))` must be `Err(ChiSquareTestError::DdofInvalid)`. A one-way ANOVA over the three samples `[6,8,4,5,3,4]`, `[8,12,9,11,6,8]`, and `[13,9,11,8,7,12]` with `NaNPolicy::Error` must give an F-statistic of about `9.3` and p-value about `0.002`. `mannwhitneyu(&[19,22,16,29,24], &[20,11,17,12], MannWhitneyUMethod::Automatic, Alternative::TwoSided)` must return U-statistic exactly `17.0` and p-value `0.1111111111111111`. A one-sample t-test of the 31-value JMP example against a population mean of `20.0` with `Alternative::TwoSided` and `NaNPolicy::Error` must give a t-statistic of `3.066831635284081` and p-value `0.004552621060635401`. Finally, `skewtest` on `[148, 154, 158, 160, 161, 162, 166, 170, 182, 195, 236]` with `Alternative::TwoSided` and `NaNPolicy::Error` must return a z-score of `2.7788579769903414` and p-value `0.005455036974740185`. All of these are exposed at the module paths `statrs::stats_tests::chisquare`, `statrs::stats_tests::f_oneway`, `statrs::stats_tests::mannwhitneyu`, `statrs::stats_tests::skewtest`, and `statrs::stats_tests::ttest_onesample`, with `Alternative` and `NaNPolicy` re-exported from `statrs::stats_tests`.
